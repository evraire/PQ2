Web External References

HTML Validator

This invaluable tool allows you to upload your HTML file and it will validate it against the HTML specification. It lists all the errors it finds, making it much easier to find mistakes in your code and fix them.

validator.w3.org

References

If you'd like to learn more about web technologies or just look something up, you can find below a couple of websites to use as starting points. It should come as no surprise that there is plenty of material on the Web for these technologies, so feel free to search for other sites if these don't meet your needs.

W3 Schools

As its name implies, W3 Schools is a site for learning HTML, CSS and JavaScript, as well as many other programming languages (including C#). It is presented in a tutorial fashion using easy to understand terminology and includes many examples of the material under discussion. It also makes for a good reference site for looking things up and refreshing your memory. W3 is actually shorthand for the www often seen in website addresses, which is itself an acronym for the World Wide Web.

www.w3schools.com

MDN Web Docs

The MDN Web Docs are maintained by Mozilla (developers of the Firefox browser) and others, and have reference documentation on HTML, CSS, JavaScript, the DOM and more. They are written in a more friendly way than the official specifications below and are well divided into individual searchable sub-topics with examples. Considerable care is taken to keep these documents accurate and up-to-date.

developer.mozilla.org/en-US/docs/Web

Specifications

These documents are the authoritative sources on web technologies that are followed by the developers of Web browsers. However they tend to be dense and use a lot of terminology that can make them harder to understand.

Hyper Text Markup Language (HTML)

The Web Hypertext Application Technology Working Group's (WHATWG) HTML Specification is the covers every single element and what can go in them, as well as every single attribute they can have and their allowed values.

html.spec.whatwg.org

Cascading Style Sheet (CSS)

The World Wide Web Consortium's (W3C) CSS Specifications cover every aspect of style sheets in detail. The most recent version has broken down the specification into multiple modules.

www.w3.org/TR/css/

Document Object Model (DOM)

The Document Object Model (DOM) treats an HTML document as a tree structure and is the standard way to interact with HTML using JavaScript. The document in document.getElementById() comes from the DOM. Its Specification is also handled by the WHATWG alongside the HTML one and is published using a similar format and language.

dom.spec.whatwg.org

JavaScript

This Ecma standard defines the current Specification of the JavaScript language.

JavaScript was originally created for the commercial Netscape browser, the ancestor to the open Firefox browser. When they decided to open their browser Netscape requested that the Ecma, an international standards organization, take over the development of JavaScript in the open as well. The Ecma published the first version of ECMAScript in 1998 and have handled every iteration since.

In other words: JavaScript is an implementation of the ECMAScript standard.

262.ecma-international.org
